3. CÁCH CHẠY LẠI TRONG VS CODE / JUPYTER
--------------------------------------------------------------------------------
Giải nén toàn bộ gói ZIP của mốc cần nộp. Mở notebook trong VS Code hoặc Jupyter,
bấm chọn kernel Python 3.14 ở góc trên bên phải (đã cài thư viện từ
requirements.txt), sau đó chọn Restart Kernel → Run All để chạy từ ô đầu tiên.
