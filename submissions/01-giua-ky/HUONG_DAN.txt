2. HƯỚNG DẪN XEM VÀ CHẠY LẠI NOTEBOOK
--------------------------------------------------------------------------------
Hai notebook ở thư mục gốc đã lưu sẵn kết quả và biểu đồ để xem trực tiếp.
Để chạy lại từ đầu:
- Trong Jupyter / VS Code: giải nén toàn bộ gói, mở Nhom15_TienXuLy_PAPI.ipynb
  hoặc Nhom15_GiuaKy_STING_PAPI.ipynb, chọn kernel Python 3.14, rồi chọn
  Restart Kernel → Run All Cells.
- Bằng dòng lệnh (mở terminal tại thư mục Nhom15_GiuaKy_STING_PAPI/ vừa giải nén):

python -m pip install -r requirements.txt
python -m nbconvert --to notebook --execute Nhom15_TienXuLy_PAPI.ipynb --output Nhom15_TienXuLy_PAPI_chay_lai
python -m nbconvert --to notebook --execute Nhom15_GiuaKy_STING_PAPI.ipynb --output Nhom15_GiuaKy_STING_PAPI_chay_lai
